# Diagrams

`agentkey-architecture.svg` (where agentkey sits beside proofline and hivevault) and `agentkey-internals.svg` (what one role key is made of) are copies, byte for byte, of the diagrams in the programme repository, where they are drawn and where `diagrams/SHA256SUMS` pins their bytes. That repository is the source of truth: a change is made there, re-hashed, and copied here again; these files are never edited in place.
